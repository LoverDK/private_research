## 文件说明

`provenance_conformal/` 同时保存研究范围、综合检索日志及三位子代理的原始工作笔记。综合备忘录的裁决优先于较早的代理记录；发现冲突应核对原始来源或数学论证，不按代理数量投票。

当前仓库只有研究文档，没有实验代码、数据集、训练权重或已完成的论文。没有运行环境安装步骤。公开文献内容通过链接引用，未收录论文全文。
